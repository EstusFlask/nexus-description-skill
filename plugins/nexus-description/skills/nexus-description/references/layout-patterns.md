# Nexus 排版与 BBCode

写正文时参考本文件；它提供可组合的模式，不规定页面必须有几个章节、使用哪些颜色或支持哪些语言。

## 阅读层级

先解决内容混排，再装饰。面向玩家的说明通常适合“用途与入口 → 当前重点 → 下载／依赖／安装 → 操作／功能 → 限制 → 低频详情／署名”。按项目调整顺序；更新历史留在已有 changelog，测试统计与内部排查过程留在开发资料。开发工具本身的关键技术条件仍应在正文说明。

标题尺寸用少量层级，强调色用在真正重要的位置。一块强强调区通常比每段都高亮更有效。已有品牌配色可继续使用；需要新方案时，浅蓝分区搭配金色重点是一种适合 Nexus 深色背景的选择，仍须在实际页面核对对比度。

双语条目可以先写语言 A，再在同一条目换行写语言 B。若内容很长，可分成语言章节或把次要语言放入清楚标注的折叠区；不要把一方读者必需的安装条件藏进名称不明的折叠块。

## 常用原生标签

| 用途 | 例子 |
| --- | --- |
| 居中标题 | `[center][size=6][b]Mod title[/b][/size][/center]` |
| 同级章节 | `[size=4][color=#8DCBEB][b]INSTALL / 安装[/b][/color][/size]` |
| 强调区 | `[quote]重点公告与下一步入口[/quote]` |
| 直接链接 | `[url=https://example.com/project]源码与说明[/url]` |
| 无序条目 | `[list][*]第一项[/*][*]第二项[/*][/list]` |
| 安装步骤 | `[list=1][*]第一步[/*][*]第二步[/*][/list]` |
| 低频详情 | `[spoiler]清楚的内容说明，然后换行写详情[/spoiler]` |
| 分隔线 | `[line]`，没有闭合标签 |

方括号语法、嵌套和颜色在编辑器与公开页上的表现可能有差别。以 Nexus 的实际渲染为准，不把本地 HTML 预览当作站点验收。优先用文字和原生标签；只有用户需要且能实际改善阅读时才添加图片，避免用大图承载必须可读的说明或引入不必要的外部图片依赖。

## 可选的招募强调模式

下面演示标题、重点框和行动入口的关系。使用时按用户的真实招募条件写内容，替换示例链接；不要直接发布示例文案。

```bbcode
[quote][center][size=5][color=#E7BD75][b]MAINTAINER WANTED / 招募维护者[/b][/color][/size][/center]
简短说明为什么招募，以及希望对方参与什么工作。

[b]相关经验：[/b]列出对本项目有帮助的经验。
[b]联系时请附：[/b]用户实际要求的作品链接或账号。

[center][size=4][b][url=https://example.com/contact]联系维护者[/url][/b][/size][/center][/quote]
```

联系入口尽量直接到用户指定的 Issue 表单、讨论或其他渠道；别替用户承诺立即接受申请、转让所有权或授予访问权限。招募理由、候选条件和审核承诺保留用户原意。

## 参考与工具

- [原导航页面](https://www.nexusmods.com/phantombladezero/mods/472)：可参考短标题、功能列表和按键条目的组织方式；其中旧版功能不代表其他项目已实现。
- [管理器页面](https://www.nexusmods.com/phantombladezero/mods/2)：可参考居中开头、统一配色、章节节奏和重点框。页面会变化，需要采用时重新查看。
- [BUTR/Converter.MarkdownToBBCode](https://github.com/BUTR/Converter.MarkdownToBBCode)：需要自动同步 Markdown 与 Nexus BBCode 时再评估。已有 BBCode 源可直接维护，无需为了排版安装转换工具。转换成功仍不等于公开页正确显示。
